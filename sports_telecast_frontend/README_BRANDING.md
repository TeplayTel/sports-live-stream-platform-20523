# Branding Instructions - Fan Engagement Live

## Favicon / App Icon

- A generic SVG stadium is set as the favicon (public/favicon.svg).
- To use your organization's logo, replace `public/favicon.svg` with your own SVG, PNG, or ICO file (recommended size: at least 48x48px, square).
- Update the `manifest.json` icons section if you add more icon sizes.

## Manifest and App Title

- `manifest.json` contains `short_name` and `name` as "FanEngage" and "Fan Engagement Live".
- Document tab title and all main branding in the app are set to "Fan Engagement Live".

## Branding Touch Points

- Header, footer, loading screens, document title, and all visible text have been updated.
- If you want a different icon, upload or edit `public/favicon.svg`, then refresh your browser to see changes.

## References

- If any Premier League or other league references/icons/logos remain, manually check in the `/src/components` assets or SVGs and remove or update as appropriate.
